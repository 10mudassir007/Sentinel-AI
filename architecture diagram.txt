architecture diagram

POST /analyze-video (MP4/AVI/MOV)
        │
        ▼
api/routes.py ──► services/video_service.analyze_video()
                        │
                        ├─► services/process_video.process_video_for_incidents()
                        │      │  OpenCV: motion scoring (absdiff → blur → threshold)
                        │      │  YOLO: core/yolo_helpers.detect_objects()
                        │      └─► Vision LLM: core/llm.get_vision_llm() per frame
                        │
                        └─► core/agent.get_incident_agent()  (LangChain agent + tools)
                               └─► core/tools: call_ambulance / call_police / call_firebrigade



























┌─────────────────────────── CLIENT LAYER ───────────────────────────┐
│  website/ (React + Vite + shadcn)  ──►  APIDemo.tsx               │
│     POST http://localhost:8000/analyze-video  (multipart upload)   │
│     └─ mock fallback response if API offline                      │
│  Other consumers: curl / Postman / future mobile app (addons.txt) │
└────────────────────────────────┬──────────────────────────────────┘
                                 │ multipart/form-data
                                 ▼
┌─────────────────────────── API LAYER ─────────────────────────────┐
│  main.py ── FastAPI app ("Sentinel AI API")                       │
│    • CORS middleware (env-configured CORS_ORIGINS)                │
│    • per-IP rate limiter (RATE_LIMIT_PER_MINUTE)                  │
│    • /health endpoint                                             │
│                                                                    │
│  api/routes.py ── POST /login, POST /analyze-video                  │
│    • POST /login: validates CNIC (13 digits) against AUTHORIZED_CNICS│
│      whitelist, mints bearer token (TOKEN_TTL_HOURS lifetime, hashed │
│      in memory, capped at 10k)                                       │
│    • POST /analyze-video: requires valid Bearer token (else 401)    │
│    • validates extension + magic bytes, enforces size limit       │
│    • streams upload to temp file (cleanup on all paths),          │
│      analysis offloaded to a thread pool                          │
│    • returns: filename, incident count, video_analysis,           │
│      agent_response (extracted final answer)                      │
└────────────────────────────┬──────────────────────────────────────┘
                             ▼
┌─────────────────────── SERVICE / ORCHESTRATION ───────────────────┐
│  services/video_service.analyze_video(path)                       │
│    • builds incident agent (core/agent)                           │
│    • runs video pipeline (services/process_video)                 │
│    • sends SYSTEM_PROMPT + video analysis to agent                │
│    • returns (video_analysis, agent_response)                     │
│                                                                    │
│  services/process_video.process_video_for_incidents(path)         │
│    • config: target_fps=1, start_pct/end_pct range                │
│    • OpenCV frame loop: FRAME_SKIP, motion scoring                │
│      (absdiff → grayscale → GaussianBlur → threshold,             │
│       adaptive threshold = max(mean×0.8, 15%) over 15-frame       │
│       history)                                                    │
│    • YOLO detection → core/yolo_helpers.detect_objects()          │
│      (only 6 interest classes, conf ≥ 0.45)                       │
│    • per-frame vision analysis w/ previous description as context │
│    • builds incidents[]: {timestamp, objects, llm_description}    │
└───────────────┬────────────────────────────────┬──────────────────┘
                ▼                                ▼
┌─────────────────────────── CORE (shared) ─────────────────────────┐
│  core/config.py                                                    │
│    • dotenv → GROQ_API_KEY (raises RuntimeError if missing)       │
│    • SYSTEM_PROMPT (verify incident → notify authorities)          │
│                                                                    │
│  core/llm.py                                                       │
│    • get_llm()        → ChatGroq "qwen/qwen3.8-27b"              │
│    • get_vision_llm() → ChatGroq "qwen/qwen3.6-27b"               │
│                                                                    │
│  core/agent.py ── get_incident_agent()                             │
│    • langchain create_agent(model, tools, system_prompt)           │
│                                                                    │
│  core/tools.py ── @tool placeholders                               │
│    • call_ambulance / call_police / call_firebrigade               │
│      (return strings only — real Twilio/VAPI integration planned) │
└────────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────── ENV / DEPLOYMENT ───────────────────────┐

│  Groq API ── chat completions (LLM + vision)                      │

│  test/ ── sample MP4s for the pipeline                            │
